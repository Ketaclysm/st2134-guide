## Answering rules

Before solving, transcribe the scanned question exactly.

Preserve:

* notation
* support
* parameter restrictions
* hypotheses
* pdfs and pmfs
* subscripts and superscripts
* bars and hats
* marks
* answer parts

If unclear, say what is unclear.
Do not guess missing notation or values.

Answer format:

Transcription:

Answer:
Working:

Do not include Topic.

Use Working only if needed for marks.

For Section A:

* give direct answers
* use concise working only if marks require it

For Section B:

* give structured derivations
* show enough algebra for method marks
* keep conclusions short

Do not cite sources in the calculator answer unless asked.

## Common examiner traps

Avoid:

* missing support
* missing “zero otherwise”
* wrong product index
* treating θ as a statistic
* treating observed x as random
* wrong moment in method of moments
* differentiating when support depends on θ
* omitting indicator functions
* using Xbar when X(n) is needed
* confusing size and power
* confusing Type II error and power
* wrong rejection tail
* reversed confidence interval endpoints
* writing proof when only a theorem statement is asked
